CASE 01 / DATA AUTOMATION

From manual reporting to repeatable workflows

Context. Data analysis and reporting often involve repeated imports, inconsistent names and formats, reconciliation, and preparation of outputs for others to review.

My approach. Identify the required inputs and validation rules; standardise records using Python, Pandas or SQL; distinguish source data from working transformations; and design exports with traceability and explicit checks.

What this demonstrates. Analytical decomposition, working with structured data, testing edge cases and communicating exceptions instead of silently assuming every record matches.

Evidence status. This is a high-level description of professional practice. Employer-owned implementations, business metrics, datasets and code are not reproduced here. A sanitised personal demonstration can be linked after it is built and reviewed.

CASE 02 / MACHINE LEARNING

Building an evaluation mindset

Context. A useful machine learning result requires more than fitting a model. Data preparation, leakage prevention, validation, appropriate metrics and analysis of limitations determine whether the result is trustworthy.

My approach. Explore data, define a task and baseline, prepare train/test splits, test methods using NumPy and scikit-learn, and evaluate performance before describing potential applications.

Current stage. University learning and personal exploration; not presented as an independently verified production ML service.

Next public deliverable. Publish a small reproducible experiment with its dataset licence, environment setup, notebook, metrics, error analysis, tests and GitHub Actions checks.

CASE 03 / RESPONSIBLE AI

AI-generated Indigenous imagery: beyond technical feasibility

Context. A UTS 43030 ethical dilemma considered commercial AI-generated imagery drawing on Indigenous Australian visual cultures.

Key concerns. Consent, cultural authority, provenance, meaningful participation, potential economic harm and the limits of simply labelling content as AI-generated.

My recommendation in the assessment. Engage with Indigenous artists, Elders or cultural advisers; create a review process; investigate training-data provenance where possible; and consider licensing and genuine participation in decisions and benefits.

Evidence. UTS Assessment 2 ethical dilemma submission, supported by cited AIATSIS and ACS guidance. Full coursework is kept outside the public website unless publication is permitted.

Reflection. Ethical development requires examining whose interests a system serves and who might carry the risks. This is a consideration to build into requirements and design, not add at the end.
