GOAL 01 / ETHICS

Working ethically and Indigenous professional capability

Why it matters. AI development is not only a technical task. It can affect consent, cultural representation, privacy, intellectual property and the communities whose knowledge or data are involved.

Evidence. My UTS ethical dilemma assessment considered a proposed commercial use of AI-generated Indigenous Australian imagery. It examined meaningful participation, cultural ownership and the professional obligation to consider harms even when a project is technically feasible.

Learning reflection. The DesignR scenario showed me that technical feasibility does not resolve consent, cultural authority or the potential effects of AI-generated imagery on Indigenous creators. In future I will identify affected communities early and review provenance, participation and possible harms before building a solution.

GOAL 02 / CYBERSECURITY

Protecting the systems behind the data

Why it matters. Data and AI systems can expose sensitive information through weak access controls, poor dependency management, insecure development or inadequate incident response.

Evidence. Two UTS cybersecurity quizzes, plus my MediSecure cybersecurity incident analysis examining exposure of sensitive health information and controls including multifactor authentication, least privilege, patching and backups.

Learning reflection. My most important insight is that restoring systems does not reverse stolen data: once information is exfiltrated, it can be reused beyond an organisation’s control. I now intend to address authentication, access control, input validation and data minimisation from the beginning of software design.

GOAL 03 / SOFTWARE TOOLS

From code that works to work that is reproducible

Why it matters. Git and automated workflows enable traceable, reviewable collaboration and make software changes easier to test and reproduce.

Evidence. GitHub Essentials Quiz 1: 9/10; GitHub Workflow Quiz 2: 10/10, recorded in UTS Canvas.

Learning reflection. I already used Python, Git and GitHub, but the activities broadened my understanding beyond version control. GitHub Actions supports automated and scheduled workflows, while GitHub Projects and Kanban boards make responsibilities, progress and collaboration clearer. I applied these ideas in this HTML, SCSS and JavaScript portfolio.
